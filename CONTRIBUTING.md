# Contributing to AccuLynx Website

## Contribution Guidelines
We welcome contributions! To contribute:
- Fork the repository.
- Create a new branch for your changes.
- Follow the project's coding standards.
- Commit your changes and push to your fork.
- Open a pull request to the main branch.
- Refer to this file for detailed guidelines.

## How to Contribute
1. Review open issues or feature requests.
2. Discuss major changes in an issue before starting work.
3. Ensure your code passes linting and tests.
4. Write clear commit messages.

## Reporting Issues
- Use the issue tracker to report bugs.
- Provide steps to reproduce, expected vs actual behavior, and screenshots if possible.

## Suggesting Features
- Open a feature request issue.
- Explain the problem and how your idea solves it.
- Suggest implementation details if possible.

## Code of Conduct
- Be respectful and inclusive.
- Provide constructive feedback.
- Avoid offensive language or behavior.

## Review Process
- Pull requests are reviewed by maintainers.
- Feedback may require changes before merging.
- Once approved, your contribution will be merged into the main branch.
